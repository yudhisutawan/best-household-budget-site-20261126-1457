# Ledgerline — Household Budget Site

Ledgerline is a working offline household budget site for the Marlowe family: a dashboard with net worth, a FIRE projection, a 6-month balance projection, and a what-if simulator, plus envelope budgets, an expense log, savings goals, and a subscription audit — all in plain static files with no build step and no network requests.

How to run: open `app/index.html` in a browser. No build step, no network.
